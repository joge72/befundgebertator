# Offene Punkte

## Werte einfügen (Copy & Paste aus der Gerätesoftware)
Geplant: In CIDP, GBS und Plexus ein Feld „Werte einfügen“, das kopierte Tabellen der Gerätesoftware
automatisch in die Eingabemaske überträgt. Später wird direkt aus dem Programm kopiert, bisher nur
Text aus Fotos (iPhone-Texterkennung) getestet.

Benötigte Beispiele, direkt aus dem Programm kopiert (gern mit erfundenen Werten):
- eine sensible Tabelle (z. B. „Rechts Medianus“ unter „NLG sensor“)
- eine F-Antwort
- ein weiterer motorischer Nerv mit Überschrift (z. B. „Links Motorisch Tibialis“)

Bekannt: Motorische Tabellen „Gebiete“ (Lat, Amp, Dur, Stim je Stimulationsort) und „Segmente“
(Dist in mm, NLG, Amp Diff in %, Temp). Die Segmente erlauben eine Gegenprüfung: NLG = Distanz /
Latenzdifferenz, Amp Diff = Amplitudenänderung gegenüber dem vorigen Ort.

## Später überdenken
- CIDP: strenge Auslegung von Tabelle 2 (dasselbe Kriterium in zwei Nerven) – bei GBS wird inzwischen
  großzügig ausgelegt.
- Plexus: EMG-Befunde (inkl. paravertebraler Muskulatur) ergänzen.
